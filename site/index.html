一扇桌面上的窗 / 01

把此刻的天空，
留在桌面。

从清晨的第一缕光，到夜雨里的车灯。打开「窗」，看你所在的地方，此刻是什么天色。

下载「窗」↓ GitHub ↗

Ubuntu 22.04 · GNOME 42 · MIT 开源

02 / 窗里的时间

天空有自己的钟。

日月星，按时升起

太阳的位置、月亮的相位和一千六百多颗星星，都按你所在的地点与时刻在本地计算。太阳走到哪儿，窗台和楼房的影子就跟到哪儿。

雨落在此刻

联网时跟随 Open-Meteo 的天气数据。从零星细雨到满窗雨幕，雨丝的疏密和速度随降水量变化，雾也会逐渐隐去远处的屋顶。

把时间拨一拨

拖动窗底的「今日天色」，看看日落后还剩多少天光，也能直接跳到某一天的某一刻。按 Esc，回到现在。

03 / 桌面窗景

让桌面也有
自己的晨昏。

把此刻设成一张壁纸，或让 GNOME 桌面随天色更新。也可以预先生成一整天的动态壁纸，关掉「窗」，桌面依然会从清晨走到夜里。

04 / 获取应用

给桌面开一扇窗。

面向 Ubuntu 22.04 / GNOME 42。界面支持简体中文、English、日本語和 Français。

获取 .deb 安装包 ↗

01. 在 GitHub Releases 下载 .deb

02. 在安装包所在目录执行

sudo apt install ./chuang_*_all.deb

03. 在应用菜单里搜索「窗」
